# Руководство администратора

## Команды бота (только для админов)
- `/export_clients` — скачать CSV со всеми клиентами
- `/export_purchases` — скачать CSV с покупками
- `/export_full_report` — полный отчёт
- `/client_info <телефон/имя>` — информация о клиенте
- `/show_categories` — список категорий с ID
- `/clean_empty` — удалить пустые категории
- `/delete_category <ID>` — удалить конкретную пустую категорию
- `/merge_categories <from_id> <to_id>` — перенести товары и удалить исходную категорию
- `/reset_assortment` — полностью очистить ассортимент (ОСТОРОЖНО!)
- `/delete_client <ID>` — удалить клиента и его покупки
- `/delete_purchase <ID>` — удалить конкретную покупку
- `/undo` — восстановить последний удалённый товар
- `/fix_sales_unique` — исправить дубликаты в таблице sales
- `/set_webhook` — переустановить вебхук вручную

## Веб-админка
- URL: `https://your-app.onrender.com/admin`
- Логин: пароль задаётся в `ADMIN_PASSWORD` или `ADMIN_PASSWORD_HASH`
- В разделе «Ассортимент» можно управлять порядком категорий (кнопка «Управление порядком категорий»)
